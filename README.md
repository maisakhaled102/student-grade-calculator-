# 🎓 نظام حساب المعدلات الذكي | Smart GPA Calculator

تطبيق احترافي بواجهة مستخدم رسومية (GUI) حديثة ومطورة باستخدام لغة Python ومكتبة Tkinter لمساعدة الطلاب على حساب المعدل التراكمي (GPA) بدقة اعتمادًا على درجات المواد والساعات المعتمدة بسهولة وسرعة.

---

# 🚀 المميزات الرئيسية (Key Features)

* 📊 دعم إدخال درجات المواد مع عدد الساعات لكل مادة.
* 🎯 حساب الـ GPA التراكمي تلقائيًا بنظام الساعات المعتمدة.
* 🧮 حساب النسبة المئوية والتقدير العام بشكل مباشر.
* 🎨 واجهة رسومية عصرية بخلفية داكنة (Dark Theme).
* 🛡️ التحقق من صحة البيانات المدخلة ومنع الأخطاء.
* 🌐 زر مدمج لفتح مستودع المشروع على GitHub.

---

# 📐 نظام حساب المعدل (GPA System)

يعتمد البرنامج على حساب المعدل التراكمي باستخدام المعادلة التالية:

GPA = Σ(Grade Points × Credit Hours) ÷ Σ(Credit Hours)

---

# 📊 توزيع التقديرات (Grading Scale)

| النسبة المئوية | التقدير | GPA |
|---|---|---|
| 90% فأكثر | امتياز 🌟 | 4.0 |
| 85% إلى 89% | جيد جداً مرتفع ✅ | 3.7 |
| 80% إلى 84% | جيد جداً ✅ | 3.3 |
| 75% إلى 79% | جيد مرتفع 🆗 | 3.0 |
| 70% إلى 74% | جيد 🆗 | 2.7 |
| 65% إلى 69% | جيد 🆗 | 2.4 |
| 60% إلى 64% | مقبول ⚠️ | 2.0 |
| 50% إلى 59% | مقبول ⚠️ | 1.0 |
| أقل من 50% | راسب ❌ | 0.0 |
